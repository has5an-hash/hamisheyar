# همیشه‌یار

**همیشه‌یار** یک دستیار فارسی برای اندروید است که بدون مدل محلی و بدون API Key اختصاصی، درخواست‌های کاربر را به **اپ رسمی ChatGPT و حساب خود کاربر** تحویل می‌دهد.

## نسخه فعلی: 0.4.0

### قابلیت‌ها

- حباب شناور روی برنامه‌های دیگر
- چت از داخل همیشه‌یار و تحویل درخواست به اپ رسمی ChatGPT
- استفاده از حساب و سهمیه خود کاربر داخل ChatGPT
- بدون دانلود مدل GGUF و بدون موتور LLM محلی
- Share Target برای متن، لینک، عکس، ویدیو و فایل
- ارسال زنده محتوای Share شده به ChatGPT یا ذخیره در صف
- دریافت اعلان‌های واتس‌اپ، تلگرام، اینستاگرام و برنامه‌های رایج SMS با اجازه کاربر
- پرسیدن «کیه؟» و «چی گفته؟» درباره آخرین اعلان
- پاسخ متنی مستقیم وقتی خود پیام‌رسان Remote Reply ارائه کند
- صندوق محلی برای اعلان‌ها و موارد Share شده
- راه‌اندازی Notification Access با مسیر سازگارتر برای نصب مستقیم APK
- تاریخچه محلی و امکان پاک‌کردن آن
- رابط RTL و Material 3

## معماری

- Kotlin
- Jetpack Compose + Material 3
- SQLite محلی
- NotificationListenerService
- Android Overlay + Foreground Service
- RemoteInput برای پاسخ سریع اعلان‌ها
- Android Share Intent برای تحویل درخواست و فایل به ChatGPT
- package visibility فقط برای اپ رسمی ChatGPT با package com.openai.chatgpt

## نحوه اتصال ChatGPT

همیشه‌یار داخل خودش از کاربر رمز عبور، توکن یا API Key نمی‌گیرد.

1. کاربر اپ رسمی ChatGPT را نصب می‌کند.
2. داخل همان اپ با حساب خودش وارد می‌شود.
3. همیشه‌یار درخواست‌ها را با Android Intent به ChatGPT تحویل می‌دهد.
4. مدل، سهمیه و پاسخ داخل حساب ChatGPT خود کاربر مدیریت می‌شود.

### محدودیت مهم

چون این معماری **عمداً بدون API** است، پاسخ ChatGPT به‌صورت رسمی و خودکار به همیشه‌یار برگردانده نمی‌شود. پاسخ داخل خود ChatGPT دیده می‌شود. همیشه‌یار برای دور زدن این محدودیت از اتوماسیون مخفی یا Accessibility سوءاستفاده نمی‌کند.

## حریم خصوصی

- رمز و نشست ChatGPT داخل همیشه‌یار ذخیره نمی‌شود.
- اعلان‌ها و صف Share برای امکانات همیشه‌یار روی گوشی ذخیره می‌شوند.
- کاربر می‌تواند منابع اعلان را جداگانه خاموش کند.
- تاریخچه محلی از داخل برنامه قابل پاک‌کردن است.
