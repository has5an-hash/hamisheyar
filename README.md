# همیشه‌یار

**همیشه‌یار** یک دستیار هوشمند فارسی برای اندروید است که تا حد ممکن روی خود گوشی کار می‌کند و برای تعامل روزمره با اعلان‌ها، پیام‌ها، محتوای Share شده و گفت‌وگوی محلی طراحی شده است.

## قابلیت‌های نسخه فعلی

- حباب شناور روی برنامه‌های دیگر
- گفت‌وگوی فارسی با مدل GGUF محلی روی دستگاه
- وارد کردن مدل بدون سرور و بدون API Key
- دریافت اعلان‌های واتس‌اپ، تلگرام، اینستاگرام و برنامه‌های رایج SMS با اجازه کاربر
- اعلام صوتی پیام جدید به‌صورت اختیاری
- پرسیدن «کیه؟»، «چی گفته؟» و فرمان‌های مشابه از حباب
- پاسخ متنی مستقیم وقتی خود اعلان پیام‌رسان قابلیت Reply داشته باشد
- ضبط ویس و آماده‌کردن آن برای ارسال به آخرین پیام‌رسان
- Share Target برای متن، لینک، عکس، ویدیو و فایل
- دو حالت Share: باز شدن فوری یا ذخیره در صف
- صندوق محلی برای اعلان‌ها و موارد Share شده
- جست‌وجوی وب اختیاری برای سؤال‌های به‌روز
- تنظیم جداگانه واتس‌اپ، تلگرام، اینستاگرام و SMS
- سیاست حریم خصوصی داخل خود برنامه
- نگهداری محلی تاریخچه و امکان پاک‌کردن آن

## معماری

- Kotlin
- Jetpack Compose + Material 3
- SQLite محلی
- NotificationListenerService
- Android Overlay + Foreground Service
- RemoteInput برای پاسخ سریع اعلان‌ها
- Android SpeechRecognizer / On-device recognizer در صورت پشتیبانی گوشی
- Android TextToSpeech
- llama.cpp از طریق `dev.ffmpegkit-maintained:llama-android`
- GGUF برای مدل محلی
- OkHttp + Jsoup برای جست‌وجوی وب اختیاری

## مدل محلی

به دلیل حجم بالای مدل‌های زبانی، فایل مدل داخل APK قرار نگرفته است. بعد از نصب:

1. یک مدل GGUF مناسب گوشی دانلود کنید.
2. وارد **تنظیمات → مدل هوش مصنوعی محلی** شوید.
3. فایل GGUF را انتخاب کنید.
4. همیشه‌یار فایل را در فضای خصوصی خودش کپی و سپس محلی اجرا می‌کند.

برای گوشی‌های معمولی بهتر است از مدل‌های کوچک و Quantized شروع شود.

## حریم خصوصی

در حالت عادی گفت‌وگو، تاریخچه، اعلان‌ها و مدل روی خود دستگاه می‌مانند. جست‌وجوی وب به‌صورت پیش‌فرض خاموش است. اگر کاربر آن را روشن کند، عبارت جست‌وجو برای دریافت نتایج اینترنتی ارسال می‌شود.

جزئیات: [docs/PRIVACY_FA.md](docs/PRIVACY_FA.md)

## محدودیت پیام‌رسان‌ها

اندروید فقط زمانی اجازه ارسال مستقیم پاسخ متنی را می‌دهد که خود پیام‌رسان در اعلانش Remote Reply ارائه کرده باشد. برای پیام صوتی، همیشه‌یار ویس را ضبط می‌کند و پیام‌رسان را با فایل صوتی آماده باز می‌کند؛ ارسال نهایی خودکار صوت در همه پیام‌رسان‌ها API عمومی و قابل اتکایی ندارد.

این محدودیت عمداً بدون Accessibility Automation دور زده نشده تا برنامه قابل‌اعتمادتر و مناسب‌تر برای انتشار در مارکت‌ها بماند.

## ساخت APK

GitHub Actions با هر Push روی `main` یک APK دیباگ می‌سازد و آن را با نام **hamisheyar-debug-apk** به‌عنوان Artifact ذخیره می‌کند.

```text
app/build/outputs/apk/debug/app-debug.apk
```
