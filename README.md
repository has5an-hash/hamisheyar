# همیشه‌یار — HamisheYar Android

## نسخه آزمایشی 0.5.0: مغز عامل‌محور روی گوشی

همیشه‌یار یک دستیار مستقل فارسی برای اندروید است. برخلاف نسخه 0.4، دیگر درخواست‌ها را به برنامه ChatGPT نمی‌فرستد؛ **پاسخ از APIهای Gemini و Groq دریافت و داخل خود همیشه‌یار ارائه می‌شود**.

### معماری
- بدون سرور اختصاصی یا پروکسی همیشه‌یار در مسیر هوش مصنوعی.
- دو اتصال Gemini و Groq هر دو **اجباری**؛ کلیدهای شخصی هر کاربر (BYOK).
- تست واقعی هر سرویس پیش از فعال‌شدن و رمزگذاری کلیدها با Android Keystore؛ بکاپ برنامه غیرفعال است.
- مسیریابی داخل Android: Groq برای جواب سریع، Gemini برای تحلیل عمیق و چندرسانه‌ای، Groq برای بازبینی تکمیلی.
- پاسخ یکپارچه داخل چت و حباب همیشه‌یار؛ تشخیص گفتار از طریق سرویس Android و پاسخ داخل تب ویس.
- تحلیل عکس و ویدیوی Share شده (فعلاً تا ۲۴ مگابایت): آپلود موقت با Gemini Files API، استخراج صدای AAC از MP4 در صورت امکان و تبدیل گفتار با Groq Whisper.
- برای لینک عمومی ویدیو، دریافت واقعی فایل در صورت وجود لینک عمومی و قابل‌دسترسی؛ لینک اینستاگرام در صورت عدم دسترسی به فایل، **قابل تحلیل ادعایی نیست** و کاربر باید فایل را Share کند.
- صندوق اعلان‌ها برای اپ‌های مجاز و پاسخ سریع در صورت پشتیبانی پیام‌رسان.

### راه‌اندازی
۱. داخل همیشه‌یار، بخش اتصال Gemini و Groq را باز کن.
۲. کلید Gemini خودت را از [Google AI Studio](https://aistudio.google.com/apikey) بساز و در برنامه وارد کن؛ «تست و اتصال».
۳. کلید Groq خودت را از [Groq Console](https://console.groq.com/keys) بساز و وارد کن؛ «تست و اتصال».
۴. مغز فقط وقتی هر دو تست پاسخ واقعی بدهند فعال می‌شود. اکنون در چت، حباب یا ویس خود همیشه‌یار سؤال بپرس.

**توجه:** ورود ساده با گوگل به معنای صدور مجوز API نیست. سهمیه‌های رایگان محدود و تابع سیاست هر ارائه‌دهنده هستند. داشتن اکانت رایگان تضمین استفاده رایگان نامحدود از API نیست.

### درباره اینستاگرام
این نسخه برای محتوای ویدیویی عمومی که فایل واقعی آن با مجوز قابل دریافت باشد تلاش می‌کند. برنامه نمی‌تواند تضمین دهد **هر ریلز اینستاگرام** از طریق لینک قابل دانلود است؛ بعضی لینک‌ها فقط صفحه HTML یا مانع دسترسی برمی‌گردانند. برنامه در آن حالت ادعای مشاهده یا صحت‌سنجی خود ویدیو نمی‌کند و Share کردن فایل را می‌خواهد. این نسخه محتوای خصوصی/DRM را دور نمی‌زند.

### وضعیت فنی و محدودیت‌ها
- کد Kotlin + Jetpack Compose، minSdk 26، targetSdk 35.
- این نسخه **debug/test** است، انتشار نهایی مارکت نیست و نیازمند تست واقعی روی گوشی‌های مختلف است.
- تحلیل ویدیو با API Gemini ممکن است هزینه/سهمیه مصرف کند؛ فایل‌های آپلودشده پس از پاسخ با درخواست حذف پاک می‌شوند (حذف سمت ارائه‌دهنده طبق سیاست خودش).
- ذخیره تاریخچه چت و اعلان‌ها در SQLite محلی است و فعلاً رمزنگاری‌شده نیست؛ هنگام ارسال اطلاعات خصوصی به سرویس ثالث دقت کن.
- دانلود ویدیو از لینک، تشخیص گفتار Android و اتصال برخی مدل‌ها به منطقه، وضعیت اینترنت و پشتیبانی ارائه‌دهنده وابسته‌اند.
- ماژول تجربی قدیمی `server/` در مخزن وجود دارد ولی برای اجرای نسخه Android 0.5.0 لازم نیست.
