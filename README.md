# همیشه‌یار — HamisheYar

## نسخه آزمایشی Android 0.5.0: مغز عامل‌محور بدون سرور اختصاصی

این نسخه با دو API Key شخصی کاربر، مستقیم از گوشی با Gemini و Groq ارتباط برقرار می‌کند. مدیریت ابزارها و نمایش پاسخ داخل همیشه‌یار است؛ دیگر برای هر پیام کاربر را به ChatGPT هدایت نمی‌کند.

### راه‌اندازی

1. در تنظیمات، از Google AI Studio کلید Gemini API خودت را بساز و وارد کن.
2. از Groq Console کلید Groq API شخصی بساز و وارد کن.
3. روی «آزمون واقعی و ذخیره امن» هر سرویس بزن. فعال‌سازی مغز منوط به هر دو اتصال است.
4. در چت، حباب یا Android Share از همیشه‌یار استفاده کن.

صرف ورود به حساب Google/Groq، مجوز API برای برنامه ایجاد نمی‌کند. استفاده از APIهای رایگان ممکن است محدود باشد یا بسته به حساب نیازمند پرداخت شود.

### امکانات

- بدون Backend/Proxy اختصاصی؛ ارتباط HTTPS مستقیم از Android به Gemini و Groq.
- رمزگذاری کلیدهای شخصی با Android Keystore و AES-GCM؛ پشتیبان‌گیری خودکار غیرفعال.
- مدیریت و ترکیب مرحله‌ای: Gemini برای تحلیل عمومی و چندرسانه‌ای؛ Groq برای پردازش سریع، تبدیل گفتار AAC به متن و بازبینی تکمیلی.
- نمایش پاسخ در خود چت، حباب و صفحه صوتی همیشه‌یار.
- دریافت متن، عکس و ویدیوی اشتراک‌گذاری‌شده با Android Share.
- نمونه‌گیری چند فریم از فایل ویدیویی و تلاش برای دریافت فایل عمومی از URL یا متادیتای عمومی og:video.
- صندوق اعلان‌ها و پاسخ سریع فقط در صورت پشتیبانی اپ مقصد.
- کنترل دسترسی اعلان/حباب و حذف تاریخچه/فایل‌های Share شده.

### محدودیت‌های مهم

- دریافت خودکار همه ریلزهای اینستاگرام تضمین نمی‌شود؛ اگر فقط صفحه یا لینک باشد، برنامه حق ندارد ادعا کند ویدیو را دیده است.
- نمونه‌برداری چند فریم مساوی مشاهده همه ویدیو نیست؛ استخراج صوت وابسته به فرمت است.
- توافق Gemini و Groq به‌تنهایی تأیید مستقل حقیقت نیست.
- این خروجی APK آزمایشی و امضاشده با کلید تست است، نه انتشار نهایی کافه‌بازار/مایکت.
- تست CI جایگزین تست روی گوشی واقعی، تست کلیدهای واقعی و آزمون سهمیه API نیست.
